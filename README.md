# 🏀 LOLSports (Next.js UI & Markup)

기존 React 기반 스포츠 데이터 UI 프로젝트를 **Next.js App Router** 환경으로 마이그레이션하며 마크업 구조와 컴포넌트 체계를 최적화한 프로젝트입니다.

---

## 📌 주요 마크업 및 퍼블리싱 특징

- **Next.js 환경 UI 컴포넌트 구조화**
  - App Router 기반 시맨틱 태그(`<header>`, `<main>`, `<section>`, `<footer>`) 구조 확립
  - 재사용성 높은 UI 컴포넌트 단위 마크업 체계 정돈

- **API 데이터 연동 및 반응형 레이아웃 검증**
  - REST API 데이터가 입력되거나 텍스트 길이가 가변적으로 변할 때 UI 구조가 깨지지 않도록 화면 크기별 사전 검증
  - Tailwind CSS를 활용해 다양한 디바이스 뷰포트에 유연하게 대응하는 반응형 그리드 레이아웃 구축

---

## 🛠 사용 기술
- **Framework & Styling:** Next.js (App Router), Tailwind CSS, React
- **Tools:** Chrome DevTools, Git, Prettier
